# Smart Parking Analytics

## 1. Project Overview
This project analyzes parking occupancy data to identify
parking usage patterns and peak hours.

## 2. System Architecture

Parking CSV Dataset
        |
        v
Python Data Ingestion
        |
        v
Pandas Data Cleaning
        |
        v
Data Quality Report
        |
        v
Parking Data Analysis
        |
        v
SQLite Database
        |
        v
Streamlit Dashboard

## 3. Technologies Used
- Python
- Pandas
- SQLite
- Streamlit
- Matplotlib
- VS Code

## 4. Dataset Information
- Original Records: 35,717
- Cleaned Records: 35,116
- Parking Areas: 30
- Average Occupancy: 48.98%

## 5. Data Quality
- Duplicate removal
- Missing value handling
- Invalid record removal
- Date and time conversion
- Occupancy rate calculation

## 6. Final Output
An interactive dashboard displaying parking
statistics, parking area analysis and peak hours.
